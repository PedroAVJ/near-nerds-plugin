# Nier Nerds plugin

Use in Codex or Claude to browse the public Nier Nerds profiles, ask what someone is into, or draft your own profile from your agent conversations. Public data lives at <https://nier-nerds.pedroavj.chatgpt.site/profiles/index.json>.

Profiles are owner-curated. The plugin must not publish raw conversations or a profile for another person without their review.
